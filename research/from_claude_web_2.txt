# Tree Structure Modeling Equations

## Core Equations

**1. Allometric Scaling (trunk/branch radius)**
$$r = r_0 \cdot \left(\frac{L}{L_0}\right)^{\alpha}$$

**2. Da Vinci's Rule (branch cross-sections)**
$$\sum_{i} d_i^n = d_{\text{parent}}^n, \quad n \approx 2\text{–}3$$

**3. Branch Length Decay**
$$L_k = L_0 \cdot \lambda^k \quad (k = \text{branching order})$$

**4. Branching Angle**
$$\theta_k = \theta_0 + \Delta\theta \cdot k$$

**5. Trunk Taper**
$$d(h) = d_{\text{base}} \cdot \left(1 - \frac{h}{H}\right)^{\beta}$$

**6. Height–Diameter Relationship**
$$H = a \cdot D^b$$

**7. Crown Radius**
$$R_c = c \cdot D^{e}$$

**8. Phyllotaxis (branch spiral angle)**
$$\phi = 137.5° \cdot g \quad (g = \text{divergence multiplier})$$

**9. Number of Branches per Order**
$$N_k = N_0 \cdot n_b^k$$

## Key Notes

- **L-systems** encode recursive branching: `F → F[+F][-F]` with $\theta, \lambda, n_b$ as params
- **Gravity/phototropism** add perturbation: $\vec{d}_{\text{new}} = \vec{d} + \gamma\hat{g} + \tau\hat{s}$ (where $\hat{s}$ = sun direction)
- **Leaf density** typically: $\rho_L \propto N_{k_{\max}} \cdot A_{\text{leaf}}$
- Values above are **representative**; real modeling uses species-specific field data
